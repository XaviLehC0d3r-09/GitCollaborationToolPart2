## Git Best Practices
- **Pull before you push:** Always run `git pull` on `main` before creating a new branch.
- **Keep commits small:** Commit logical chunks of work rather than massive changes all at once.
- **Write clear commit messages:** Use short, descriptive messages that explain *what* changed.
- **Use feature branches:** Never commit directly to `main`; always work in a separate branch and open a Pull Request.
